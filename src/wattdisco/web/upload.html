Strava sign-in isn't available in this version. Save the .fit file and upload it at strava.com/upload, or use your own Strava API app: create one at strava.com/settings/api with localhost as authorization callback domain, then put its keys in a file named .env in the Watt Disco data folder (where your rides are) and restart the app:

STRAVA_CLIENT_ID=12345
STRAVA_CLIENT_SECRET=…

Sign in once with your Strava account, nothing else to set up. Watt Disco asks to upload activities; after that, rides go up with one tap, or on their own after every ride if you switch that on.

Strava lets Watt Disco connect only a limited number of riders for now. If it says the connection is full, save the .fit file and upload it at strava.com/upload.
